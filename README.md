- 실험은 **텍스트 분류에 특화된 사전 학습 언어 모델(PLM)**과 **문장에 일정한 패턴이 있을 수 있다는 가정** 하에 이를 포착하기 위해 CNN을 사용하는 시도를 했고, 저는 PLM을 담당했습니다.

## Data Source

- 1차: [Korean Hate Speech Dataset](https://github.com/kocohub/korean-hate-speech), [Korean UnSmile Dataset](https://github.com/smilegate-ai/korean_unsmile_dataset)
    - 선정 이유: 예측할 문장의 특성이 **오탈자, 신조어, 은어가 사용된 비공식적 어투의 구어체 문장**일 것이라 판단했습니다. 따라서 관련 연구에서 많이 사용된 두 데이터셋의 문장을 직접 라벨링할 계획을 세웠습니다.
- 2차: AI-Hub [텍스트 윤리검증 데이터](https://www.aihub.or.kr/aihubdata/data/view.do?currMenu=115&topMenu=100&aihubDataSe=data&dataSetSn=558) (최종 약 41만 문장)
    - 변경 이유: 라벨링을 위한 기준 설정을 위해 여러 보고서와 논문을 참고했으나 자료마다 정의에 조금씩 차이가 있어 **기준을 설정하기 모호**했고, 임의로 설정한 기준으로 일부 데이터를 라벨링한 결과는 **신빙성에 문제**가 있었습니다.
    - 선정 이유: 목표한 특성에 부합하며 라벨링 작업자, 전문가 등 여러 단계를 거친 데이터 구축 과정이 합리적이라고 판단했습니다. 비윤리 강도가 강한 문장이 부족하다는 문제가 있었으나, 해당하는 데이터만 추가로 보완해 사용하기로 결정했습니다.

# My Role

## 모델링 및 개선

### 1. 베이스 모델 선정: BERT, ELECTRA

- BERT는 **인코더만으로 이루어져 분류 문제에 더 적합할 것**으로 판단했고, ELECTRA는 BERT의 학습 방법을 변경해 **성능과 효율을 모두 개선**했다고 주장하는 모델이기 때문에 사전 학습된 모델 중 최고의 성능을 보일 것으로 예상해 선정했습니다.

### 2. PLM 선정: KcBERT, KcELECTRA

- Fine-Tuning할 데이터의 특성을 고려해 **비슷한 데이터(뉴스 댓글)로 사전 학습된 모델**을 선정했습니다.

### 3. 성능 평가 방안 선정: Confusion matrix - Accuracy, F1-Score

- **이진 분류 시에는 정확도가 가장 중요**하다고 생각했기 때문에 Accuracy를 선정했고, 다중 클래스 분류 시에 **데이터가 불균형하기** 때문에 F1-Score도 함께 사용했습니다.

### 4. 문제 해결 절차 구상

- 최종 목표는 다중 클래스 분류지만 학습 시간 단축 및 단계적 문제 정복을 위해 이진 분류부터 시도하며 성능 개선에 힘썼습니다. 실제로 이진 분류는 최소 15분 ~ 최대 1시간 내외로 학습이 가능했지만, 다중 분류는 학습에 최소 2시간 30분이 필요했습니다.

### 4. 성능 개선 방안 탐색 및 적용: 하이퍼 파라미터 조정, 데이터셋 비율 조정, 비식별 데이터 제외, 손실 함수 변경, 데이터 구성 변경

- 성능 변화(F1-Score / Accuracy)
    - 이진 분류 : 87.1 / 87.1 → 91.0 / 82.1
    - 다중 클래스 분류: 85.2 / 70.7
- Accuracy 성능 하락 원인은 True Negative 성능 하락에 있었고, 분류된 데이터를 비교한 결과, 문장의 비윤리 강도가 애매해 라벨링이 잘못 되어 있거나 모델이 오해할 만한 데이터들이 다수 존재했기 때문이었습니다. 비윤리 강도가 강한 데이터를 보완하여 개선할 계획을 세웠으나 시간이 부족하여 진행하진 못했습니다.
